Problem 13.1.10.

Any non–empty set with operations satisfying Axiom 13.1.1 through Axiom 13.1.9 is called a field.
🔗

(a)

Show that the set \(\{0\}\) with operations \(0+0=0,\ 0\cdot 0=0\) satisfies all the axioms of a field. What is the multiplicative identity in this field?
🔗
🔗

(b)

Show that in any field \(0\cdot x=0\) for all elements \(x\) in the field.
🔗
Hint.
\(0\cdot x+0\cdot x=\left(0+0\right)\cdot x=0\cdot x\text{.}\)
🔗
🔗
🔗

(c)

Show that if a field contains \(x\neq 0\text{,}\) then \(1\neq 0\text{.}\)
🔗
Hint.
If \(1=0\) then \(1\cdot x=0\cdot x\text{.}\)
🔗
